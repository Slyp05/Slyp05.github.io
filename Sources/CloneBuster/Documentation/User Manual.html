CloneBuster User Manual

Prove you made it first: every version of your project timestamped from the moment you import the package.

CloneBuster records every version of your project and your source art from the moment you import it, and has each version dated by two independent timestamp services. It changes nothing in your build: it runs in the Unity Editor only. The only thing it sends out is a hash, a fingerprint that reveals nothing about your files.

Install it, then leave it

Import the package. If you use version control, commit the CloneBuster Vault folder it creates. That's all: every save is recorded and timestamped in the background, with nothing to set up or start. For more information, refer to Install CloneBuster.

When a copy appears

  1. Go to Tools > CloneBuster > Exporter.
  2. Tick the files the copy takes from.
  3. Select Export proof, paste the copy's store link, then select Export.
  4. Upload the export folder somewhere public and paste its link into Notice text.txt.
  5. Send the notice to the store that hosts the copy.

For more information, refer to Export a proof and File a takedown notice.

Show how your work came to be

To post a dated timelapse of a file, select it on the Exporter's Reel tab, then select Export reel. For more information, refer to Export a process reel.
