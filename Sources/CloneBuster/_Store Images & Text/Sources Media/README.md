# Sources Media

Sources for the Asset Store marketing images and the editor mark. Every image is an HTML page here, rendered to PNG with headless Chrome. Edit the HTML or `illustrations.js`, re-render, never edit a PNG by hand.

| Output | Source |
| --- | --- |
| `../Cover 1950x1300.png` | `cover.html` |
| `../Card 420x280.png` | `card.html` |
| `../Social 1200x630.png` | `social.html` |
| `../Icon 160x160.png` | `icon.html` |
| `Assets/CloneBuster/Editor/Icons/CloneBuster Mark.png` | `mark.html` |
| `Assets/CloneBuster/Editor/Icons/d_CloneBuster Mark.png` | `mark.html?dark` |

Render all six with `sh render.sh` (Git Bash, from this folder), or one with `sh render.sh card.html "../Card 420x280.png" 420 280`. Set `CHROME` if Chrome is not at its default install path.

`illustrations.js` generates the illustrations the pages place with `<image>`. Each illustration is framed on its measured bounds, and the generator writes its `<image>` placement into each page, fitted and centred in that page's box (set at the end of `illustrations.js`). Run `node illustrations.js` after editing it, then re-render:

- `illustration.svg`: the original's three stamped prints and the robot's clone, used by the cover, below the title, and by the social image.
- `illustration-card.svg`: the same scene drawn at its own scale for the card's 840x560 canvas.
- `illustration-icon.svg`: the three prints stacked, the final one in front, with a large stamp on its top-right corner.

The card and the icon are drawn on a canvas twice the output size and rendered at half size.

The mark, the CloneBuster window's tab icon, is drawn by hand in `mark.html`: the icon's prints and timestamp at 32x32 (shown at 16x16), in one color per skin, Editor Foundations' icon grey (`#555555` light, `#c4c4c4` dark), on a transparent background. Shapes stay apart through cut-out casings rather than color. The PNGs import as Editor GUI textures, and the window loads them by GUID, so the package folder can move.

## Asset Store marketing image rules

From Unity's [What makes a great key image](https://support.unity.com/hc/en-us/articles/210122403-What-makes-a-great-key-image-and-are-there-any-size-restrictions-):

| Image | Size | Allowed text |
| --- | --- | --- |
| Icon | 160x160 (shown at 80x80) | None |
| Card | 420x280 | Asset title, publisher name or logo |
| Cover | 1950x1300 | Asset title, publisher name or logo, a tagline |
| Social media | 1200x630 | None. Unity may skip assets with text on this image for its paid social promotions. |

All images: no Unity logo, sale banners, watermark or default skybox; not only a screenshot of the Editor; not blurry, stretched or cropped; each size designed for its display size. These images are generated by code, not by generative AI.

## Visual language

- Bold and playful, to match the name: the clone gets caught. A clone can copy the finished game, not the dated history of how it was made, so the original is a stack of dated versions and the clone, held up by the robot that made it, has only empty outlines where its history would be.
- Background: electric blue, radial from `#3d5cff` through `#2140f0` to `#1428b8` at the edges, with a faint halftone dot grid (white, opacity 0.07).
- Subject: one original 2D platformer screen (a red block hero, a platform, a coin, a flag), at three stages: greybox, flat colours, final art. A game screen, so a buyer reads "my game", never a mascot or character that reads as an art pack.
- Prints: white cards with an ink `#0a1344` outline and a hard ink shadow, no blur.
- Stamp: a yellow `#ffd400` disc with a clock face, ink outlined, on the top-right corner of each version of the original: the timestamp. No check mark, no text.
- Protection: each stamped print has a flat border in the stamp's yellow and ink around its card, joined to the clock, as if the clock protects the picture. The clone has none.
- Clone: the final screen, identical to the original as real clones are, tilted. A robot (pale metal head, startled red LED eyes, red-tipped antenna) peeks over its top edge and grips its sides: the AI that made it, caught. Behind it, two white dashed empty outlines where its history would be. Red `#ff3b4f` is the robot's colour and is used for nothing else.
- Text: title white `#ffffff` in Segoe UI Black with a hard ink shadow; tagline yellow `#ffd400`, Segoe UI Variable Display semibold. Text top left, the scene across the lower part.
- Icon: the three prints and a large stamp. No clone: it does not read at 80x80.
- Its own identity, distinct from the sibling packages: not indigo denim, not cream paper, no Catppuccin accents from the documentation theme.

## Wording

- Store title (design): `CloneBuster: Anti-AI Proof of Creation`. The card shows `CloneBuster` only.
- Tagline (cover only): `Prove you made it first.`, the pitch in [Story](../../_Design/Story.md#pitch).
- No publisher name.
- Claims follow [Story](../../_Design/Story.md#claims): never "AI-proof", "unbreakable" or that copying is stopped; the reel proves when each version existed, not who or what made it.
