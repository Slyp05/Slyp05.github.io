Scry panels and answers

What Scry knows about each member, and how to change the way Scry handles it.

The Scry button

The crystal ball at the right of each row is its Scry button, colored by what Scry knows about the member: red for an error, yellow for a warning. Select it to open the member's Scry panel: its declaration, which opens in your code editor, what Scry knows about it with the line each fact comes from, and the controls that change how Scry handles it, such as its Style and Visibility.

The component's header has its own crystal ball, which counts the component's problems and opens a panel listing them, and a magnifying glass that searches the component's members.

Answers and attributes

The controls in a Scry panel that change how Scry handles a member are answers. For example, Visibility shows a member, hides it, or makes it read-only, and Style decides who draws it: Scry, or Unity as Unity's Inspector would. Set Style in a field's panel for that field, or in the component's panel for its whole Inspector.

Picking a value overrides the answer's default, as a prefab override does, even when you pick the value it already had. To return to the default, right-click its line and select Clear Answer. Scry saves your answers in the project's UserSettings folder, which version control usually leaves out, so they change only your own Inspector.

To apply an answer for everyone working on the project, write it into the script as an attribute: right-click its line, select Copy as Attribute, and paste the attribute on the member or the type. An attribute sets the default; each user can still answer otherwise, unless the attribute sets Force = true.

[Scry.Layout.AsWritten]A class or structMembers in the order and structure the code declares.
[Scry.Layout.Sorted]A class or structMembers grouped by kind: serialized fields, other fields and properties, events and methods, then static members.
[Scry.Visibility.Shown]A field, property, method or eventShown and editable, even when the member is not public.
[Scry.Visibility.ReadOnly]A field, property, method or eventShown, read-only.
[Scry.Visibility.Hidden]A field, property, method or eventNot shown. The search still finds it.
[Scry.EffectIntended]A method or propertyNever asks before running it.
[Scry.NotLive]A method or propertyNot live: a getter or method updates when you select its name, and a setter applies on release or Enter.

For every attribute, refer to the Public API.
