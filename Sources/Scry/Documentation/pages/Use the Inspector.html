Use the Inspector

What you can edit, and how to find, build and preview values.

Read-only members

A member only its own type's code can use starts read-only: a field that is not public and not serialized, a property whose getter or setter is not public, a method or event that is not public. It shows dimmed, and a read-only method runs only once Scry proves it changes nothing. To make one editable, set its Visibility to Shown, or for everyone with [Scry.Visibility.Shown].

Search members

Select the magnifying glass in the component's header and type part of a name. The search also finds hidden members, members Show leaves out, and members inside the values your fields hold. Enter jumps to the first match, Esc clears the search.

Build, clear and reset values

A field holding None folds open to build a value: pick the type and the constructor, then select Create.

📷 img/build
A None field folded open to build a value, with its type, constructor, arguments and Create button.

The trash button at the right end of a line sets the value back to None. To return a field to its initializer, right-click it and select Reset.

Fold and open values

Alt-click a fold arrow to open or close everything below it, or a region's header to open or close every region. The Inspector icon on an object reference opens the object in a Properties window. Rest the pointer on an asset, a curve or a gradient to see it larger.

Preview code before it runs

Rest the pointer on the name of a method or a property: Scry marks the values it reads and writes, and previews the values a run would leave. To turn either off, refer to Preferences.
