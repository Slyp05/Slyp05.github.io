Row marks

📷 img/row-marks
Rows showing the saved bar, a prefab override, an underlined static, a struck-through label, bound boxes and a unit.
MarkDescription
Grey bar at the left edgeSerialized: Unity saves the value with the object.
No bar on a fieldNot serialized: an edit lasts until the next domain reload.
Underlined labelStatic, shared by every instance.
Struck-through labelThe value does not matter in the current state, such as a field the code uses only while a toggle is on, while the toggle is off.
Yellow or red outlineA value the code rejects.
Box at an end of a number fieldThe nearest limit the code sets on that side: a minimum or maximum (0 ≤), a range of values it excludes (∉ -1, 1), the value where it wraps around (360 ↻), or a value it rejects (≠ 0). A value typed or dragged past it becomes the value the code would make of it.
Muted suffix inside a field, such as sThe value's unit, from how the code uses it: s for a value passed to WaitForSeconds, °/s for a turn speed multiplied by Time.deltaTime and added to an angle.
Muted editor after a nameThe member does nothing in a player build.
Muted dev after a nameThe member does nothing in a release build.
Italic name, such as ResultA name Scry gives, where the code has none.
Diagonal stripes across a rowA member that is hidden, or left out by Show, shown because the search found it or its Scry panel is open.
Dimmed name and valueRead-only.
Trash button at the right end of a lineSets the value to None.
Spinner after a nameThe member's code changed, and Scry is still analyzing it.
Pause icon after a nameA live value paused because one read takes too long for every refresh.

Code marks

📷 img/code-marks
Method rows with the pure, undoable and clock icons, a method that asks first, and a larger method folded open to its outputs.
MarkDescription
Name on a faint fillCode that runs when you select it: a method, an event to raise, a getter Scry reads only on request, or a property that has only a setter.
Name ending with ()A method. One that takes or returns more than one value folds open to its parameters, its button and its results.
Eye iconThe code changes nothing, so it runs freely.
Circular arrowsThe code changes only its object, so a run is one undo step.
ClockA coroutine or an asynchronous method.
Ellipsis after the nameThe code does more than Scry can undo, so it asks before it runs.
Light box, an outline with no fillA value computed by code, such as a get-only property or a method's result.
Parameter types, += and method names, for example (int) += Take DamageAn event: the types it passes, then the methods listening to it.

ColorDescription
RedAn error: something that fails at runtime, or code that breaks builds.
YellowA warning: the code runs on with a result you may not intend.
WhiteInformation only.

Scry panel

📷 img/scry-panel
A row's Scry panel open: the declaration, a fact with its line and a fix button, and the Style and Visibility answers.
ItemDescription
DeclarationThe member's declaration, with a link to its line in your code editor.
RemarksThe <remarks> of its doc comment.
FactsWhat Scry knows, each with its line, and a fix where Scry has one, such as Add Tag "Enemy".
StyleScry or Unity, for a serialized field.
VisibilityShown, Read-Only or Hidden.
Getter, ResultLive reads the value again at every refresh; On Request reads it only when you select its name.
Before It Runs, Before the Setter AppliesAsk or Don't Ask Again, for code that asks first.
Layout, ShowFor a field holding a class or struct, which folds open to its members: their order and which kinds show.
LinksThe <see href> links of its doc comment.

Component header

📷 img/component-header
A component header with the magnifying glass, and the crystal ball counting the component's problems.
📷 img/component-panel
The component's Scry panel open, listing its problems, its hidden members, and the Style, Layout and Show answers.
ItemDescription
Magnifying glassSearches the component's members by name, including hidden members and members of the values its fields hold.
Crystal ballOpens the component's Scry panel. The number counts its warnings and errors.
ProblemsEvery warning and error, with a button that adds any component the code needs on the GameObject.
HiddenEvery hidden member, with Unhide.
StyleScry, or Unity for Unity's default Inspector, for every component of the type.
LayoutAs Written, in the order and structure the code declares, or Sorted, grouped by kind: serialized fields, other fields and properties, events and methods, then static members.
ShowWhich kinds of member show: fields not serialized, properties, methods, events, and static members, which are off by default. Serialized fields always show.
Clear My AnswersClears your answers for the type and its members.

Doc comments

📷 img/doc-comments
A script with a region, headers, a line and a hint, beside the Inspector it produces.
In the scriptIn the Inspector
/// <summary>The row's tooltip.
/// <param>, <returns>, <typeparam>Tooltips on a method's parameters, result and type arguments.
/// <remarks>, <exception>, <see href>The Scry panel.
/// text on its own line, above a memberA header.
/// text at the end of a member's lineA hint under the row.
/// and three or more of one symbol, for example /// -----A line.
/// and text between runs of one symbol, for example /// ===== Combat =====A line titled with the text.
#regionA group that folds.
Extra blank lines between membersSpace between rows.

Fields Scry draws ignore Unity's layout attributes, [Header] and [Space]; fields whose Style is Unity keep them. A [Tooltip] is the row's tooltip, over the /// summary. To read // comments instead of ///, refer to the project settings.
