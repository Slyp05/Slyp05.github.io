Get started

Install Understudy, set up a test assembly, write a first test, and learn what spies, stubs, fakes and leaks are.

Understudy runs inside the Unity Test Framework: your tests stay NUnit tests, in a test assembly that references Understudy. For a first look at what Understudy does, refer to the Quick Usage Guide.
