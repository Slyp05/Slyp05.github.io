Public API Stubs

What Stub entry points return: the member is replaced with the answers your test sets. Explained in Stub members. Every list a stub returns is live: it follows what the code under test does as it runs. An answer with out, ref or in parameters binds to an overload Understudy generates into your test assembly: refer to Out and ref parameters.

Methods

StubbedMethod

sealed

A stub of a void method: the real member never runs, and each call the code under test makes that the selection matches is recorded. With nothing declared, a call does nothing. When it comes from a table, it covers its own instance only.

Every member throws InvalidOperationException once the test or fixture this stub belongs to has finished. A method that takes an answer throws ArgumentNullException when it is null, and ArgumentException when its parameters fit none of the forms its row lists.

Members
CallList Calls { get; }The calls recorded, in the order the code under test made them.
StubbedMethod Do(Action replacement)Replaces the call. The answer takes no parameters or the call's arguments. A throw in it makes the call throw. It replaces any previous answer. Overloads take up to 16 parameters.

StubbedMethodTable<TInstance>

sealed

Stubs a void method on any instance: one stub per instance, reached by the instance. An answer set through the table serves every instance, existing and future, until one is set for a single instance; the last one set wins.

Every member throws InvalidOperationException once the test or fixture this stub belongs to has finished. A method that takes an answer throws ArgumentNullException when it is null, and ArgumentException when its parameters fit none of the forms its row lists.

Members
StubbedMethod this[TInstance instance]The stub of one instance's calls. Throws ArgumentNullException when the instance is null.
CallList Calls { get; }The calls recorded on every instance, in the order the code under test made them, each with its instance.
StubbedMethodTable<TInstance> EachDo(Action replacement)Replaces the call on every instance. The answer takes no parameters, the call's arguments, or the instance then the arguments. A throw in it makes the call throw. It replaces any previous answer, for every instance. Overloads take up to 16 parameters.
