Write tests

Test common Unity code, select members, stub them, check what the code under test did, fake fields, properties and events, and run members for real.

A test with Understudy is an ordinary NUnit test: it declares spies, stubs and fakes, runs the code under test, and checks the result with NUnit constraints. For ready examples of what game code reaches most often, start with Test common Unity code; each of its examples links to the page that covers the feature in full.

LifetimeWhen a spy, stub or fake starts and ends, and how each test starts it fresh.
