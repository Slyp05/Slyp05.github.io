Concordance User Manual

Coordinate the scripts that write the same value: track every write, combine their changes, and observe the value.

Concordance is a Unity package that coordinates the scripts that write the same field or property. There is no need, for example, to cache a value and write it back when an effect ends: two overlapping gravity zones both change a rigidbody's gravityScale, and leaving one zone no longer resets the other's change.

Concordance rewrites your code after Unity compiles it, so it works on any member your scripts write, Unity's own included, with no wrapper type to adopt. Use it in the following areas:

  • Track: the Concordance window lists every write to a member in your project, shows how its value is computed in Play mode, and flags conflicting writes: two objects overwriting each other's value. In the Editor, a member you watch also records who changed it, when, and from which line.
  • Combine: each script writes a modifier, a change layered on the value, instead of overwriting it. Modifiers apply in an order you set per member, and end with the object that wrote them.
  • Observe: Observe turns any member into a change event, including values Unity raises no event for, such as Time.timeScale.

To start using Concordance in a few steps, refer to the Quick Usage Guide.
