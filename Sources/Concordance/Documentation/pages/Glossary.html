Glossary

Look up the terms the Concordance documentation uses.

Terms

TermDefinition
Base valueA member's value without its modifiers. Plain writes set it.
Conflicting writesTwo objects setting the same member with plain writes, each replacing the other's value.
Driven memberA member written at known moments of the frame by code Concordance doesn't rewrite, such as animation.
Intended writersScripts marked as meant to replace each other's writes on a member, so their writes aren't flagged.
KeyWhat tells apart several modifiers of one owner on one member.
MemberA field, a property, or a getter and setter method pair, such as Rigidbody2D.gravityScale.
ModifierA change layered on a member's value, written with the quick syntax or the regular syntax.
Modifier functionWhat a modifier does to the value before it, as an object (ModifierFunction<T>): passed to Modify, or picked in the Inspector window through a [SerializeReference] field. A modifier copies it when written.
Modifier orderThe order in which the scripts that modify a member apply, set by phases and in the Concordance window.
ObserverA handler that Observe calls each time a member's value changes.
OwnerThe object a modifier belongs to. The modifier ends when the owner is destroyed.
PhaseWhere a script's modifiers apply in a member's order: Earliest, Early, Default, Late, then Latest. Set with an attribute such as [ModifierPhase.Late].
Pinned scriptA script you dragged into place in a modifier order.
Plain writeAn assignment or setter call without (Modifier). It sets the base value.
Quick syntaxAn assignment with (Modifier) before the value, such as speed *= (Modifier)0.5f, which sets a modifier, and Modifier.Stop, which stops it.
RecombineComputing a member's value again: its modifiers apply in order to its base value. Writing or stopping a modifier and a plain write recombine the member. Recombine() recombines it at once, from its current value, to take in an untracked write.
Regular syntaxThe Modify and StopModifying methods, which do what the quick syntax does, with an owner, a key and a local order.
SnapshotA part of a modifier's value other than the member itself, evaluated once when the line runs.
Special caseA member Concordance handles differently: a driven member, an unmodifiable member, or a getter and setter pair.
Tracked codeCode whose writes Concordance sees as they happen: every assembly that references Concordance, including Assembly-CSharp.
Unmodifiable memberA member the engine computes from its own previous value, such as a velocity, which can't take modifiers.
Untracked writeA write from code Concordance doesn't rewrite, such as a precompiled DLL. It becomes the base value at the member's next recombine.
Watched memberA member whose history the Concordance window records.
