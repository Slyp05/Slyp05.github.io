Keep your line, make it a Modifier

A stun that ends mid-cutscene no longer lets the character walk.

Without Concordance
With Concordance
Stun.cs
void Begin() => movement.enabled = false;
void End() => movement.enabled = true;
Cutscene.cs
void Begin() => movement.enabled = false;
void End() => movement.enabled = true;
The stun ends: the character walks mid-cutscene
Stun.cs
void Begin() => movement.enabled = (Modifier)false;
void End() => movement.enabled = Modifier.Stop;
Cutscene.cs
void Begin() => movement.enabled = (Modifier)false;
void End() => movement.enabled = Modifier.Stop;
The character moves again only once both have ended
