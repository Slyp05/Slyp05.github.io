Requirements

Settings Kit supports Unity 6.0 and newer, on every platform Unity builds for.

Install the package

To add Settings Kit to your project:

  1. Go to Window > Package Manager.
  2. Select the My Assets tab, then select Settings Kit.
  3. Select Download, then select Import.

Unity imports the package into Assets/Settings Kit. You can move that folder anywhere under Assets. To declare your first page, refer to Get started.

Run the demo

The Demo folder uses every feature in a working example: build, per-platform, editor and user settings, validation, migration, a custom drawer, an asset reference, and a runtime reader.

It adds a Settings Kit Demo page to Project Settings and to Preferences, and a Tools > Settings Kit > Demo menu that logs the current values and opens the pages.

📷 img/demo_menu
The Tools > Settings Kit > Demo submenu showing its entries: Log Current Settings, Open Preferences Page, and Open Project Settings Page
Warning: Delete the Demo folder before you ship. Its build settings are included in every build made with the folder in the project.
