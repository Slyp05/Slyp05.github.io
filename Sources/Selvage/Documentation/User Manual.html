Selvage User Manual

Inject the objects your scripts need, from your scenes, assets, classes and code.

Selvage is a dependency injection framework for Unity. A script declares the objects it needs with [Inject], and Selvage finds and assigns them: components from your scenes, your assets, instances of your own classes, or objects your code creates. Where each object comes from is set once, in the provider list of your project, so your scripts don't look for anything themselves.

To inject your first members in a few steps, refer to the Quick Usage Guide. If you're familiar with dependency injection containers, refer to What sets Selvage apart.
