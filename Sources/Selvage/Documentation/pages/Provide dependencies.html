Provide dependencies

Provide components, instances of your classes, assets and objects your code creates.

Each provider in the provider list gives dependencies from one source. By default, the list holds the four providers that ship with Selvage.

Every object you provide has a lifetime, which decides whether members share one object, each receive their own, or borrow one from a pool.
