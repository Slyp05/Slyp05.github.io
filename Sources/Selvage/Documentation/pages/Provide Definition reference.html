Provide Definition reference

The properties of a Provide Definition asset.

A Provide Definition is an asset that makes the Asset Provider provide the assets of its folder, or a list of assets. To create one, go to Assets > Create > Selvage > Provide Definition. For more information, refer to Provide assets.

Properties

PropertyDescription
ProvidesWhich assets the definition provides:
  • This Folder: the assets in its folder. This is the default.
  • This Folder and Subfolders: also the assets in the folders inside it.
  • List: the assets in its list, wherever they are.
AssetsThe assets the definition provides. Appears when Provides is List.
LifetimeShared: every member receives the same asset. Separate and Pooled: each member receives its own instance of a prefab, or its own copy of any other asset. For more information, refer to Lifetimes.
Runtime CopyWith the Shared lifetime, gives every member one copy of an asset instead of the asset itself, so changes made in Play mode never reach the asset. A prefab is always given as an instance.
Has PreferenceGives the assets a preference, which decides which members receive them when several assets could fit. Shows the preference settings.

Under the properties, the Inspector window lists every asset the definition provides.

Preference settings

Has Preference shows the preference settings, grouped under Member, Context Class and Context GameObject. For a description of each setting, refer to Preference settings.
