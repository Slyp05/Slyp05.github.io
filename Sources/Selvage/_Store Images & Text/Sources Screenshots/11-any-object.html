Every object, injected the same way

Fields or properties, in any object. No base class, no special method.

MonoBehaviour
class Player : MonoBehaviour
{
    [Inject] IInventory inventory;
}
ScriptableObject
class Shop : ScriptableObject
{
    [Inject] IInventory inventory;
}
Plain C# class, created with new
class Trade
{
    [Inject] IInventory Inventory { get; set; }
}
Static class
static class Cheats
{
    [Inject] static IInventory inventory;
}
