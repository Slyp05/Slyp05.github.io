A channel works like a key, but as a hint: fixed in code, or read from a field each time it is injected.

Fixed
[Inject, Channel("Music")] IAudioBus bus;
Read from a field
[SerializeField] string language = "fr";
[Inject, DynamicChannel(nameof(language))] IVoice voice;
The candidates
[Provide, Preference(Channel = "fr")] class FrenchVoice : IVoice { }
[Provide, Preference(Channel = "en")] class EnglishVoice : IVoice { }
