Not even an attribute

With Inject by Default, plain fields are injected in scripts that never mention Selvage.

using Selvage;
using UnityEngine;

public class Cannon : MonoBehaviour
{
    [Inject] Rigidbody body;
    [Inject] ITargeting targeting;
    [Inject] AudioClip fireSound;
}
Fields you assign yourself keep their value.
Project Settings > Selvage
Pick the options every field receives. They combine freely.
