Pooling, built in

Give a dependency the Pooled lifetime. Members borrow one and give it back.

[Provide(Lifetime.Pooled)]
public class Explosion : IResettable
{
    public bool TryReset() { ... }
}

public class Enemy : MonoBehaviour
{
    [Inject] Explosion explosion;
}
1
An enemy spawnsit borrows an Explosion from the pool
2
The pool grows as neededfor classes, prefabs and scene objects alike
3
The enemy is destroyedTryReset runs, and the Explosion goes back
