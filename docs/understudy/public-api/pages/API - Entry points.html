Public API Entry points

Declare spies, stubs, fakes and Real, match arguments, and declare non-deterministic members. Explained in Select a member and Detect leaks.

Roles

Spy

static

Creates spies: the real member runs, and what the code under test does with it is recorded. A spy belongs to the NUnit test or fixture that creates it, and starts fresh in every test. Explained in Check what the code under test did and Spy on caught exceptions.

Every method throws InvalidOperationException outside an NUnit test, or when its selection was not woven (Catch, which takes no selection, only outside an NUnit test).

Stub

static

Creates stubs: the member is replaced with the answers the test sets with Returns and Do, and each access the selection matches is recorded as a spy records it. With nothing declared, a stub does the C# default. A stub belongs to the NUnit test or fixture that creates it, starts fresh in every test, and the last stub, fake or Real declared on an access decides it. Explained in Stub members.

Every method throws InvalidOperationException outside an NUnit test, or when its selection was not woven.

Fake

static

Creates fakes: the member is replaced with a working in-memory stand-in, a stored value for a field or property, stored handlers for an event, and each access the selection matches is recorded as a spy records it. A fake belongs to the NUnit test or fixture that creates it, starts fresh in every test, and the last stub, fake or Real declared on an access decides it. Explained in Fake fields and properties and Fake events.

Every method throws InvalidOperationException outside an NUnit test, or when its selection was not woven.

Real

static

Declares that a member runs for real on purpose. Declared after a stub or fake, it sends the accesses it matches to the real member; leak detection doesn't warn about the accesses it covers. It records nothing, and belongs to the NUnit test or fixture that declares it. Explained in Run members for real.

Every method throws InvalidOperationException outside an NUnit test, or when its selection was not woven.

Matchers

Arg

static

Matchers for the arguments of a selection. Any other argument matches as NUnit's Is.EqualTo does. Understudy generates it as an internal class into each assembly that references Understudy, such as your test assembly, with the Ignored overloads its events need.

Static methods
ref T Any<T>()Matches every value. In an out or ref position, it stands for the argument and never filters. Throws InvalidOperationException when called anywhere but inside a selection.
ref T That<T>(IResolveConstraint constraint)Matches the values that satisfy an NUnit constraint, such as Arg.That<float>(Is.GreaterThan(50f)). Throws InvalidOperationException when called anywhere but inside a selection.
void Ignored()Names an event in an Event selection, as the right side of += or -=: Fake.Event(() => player.Died += Arg.Ignored). It fits a void delegate with up to 16 parameters, and Understudy generates the overloads an event with a result or with out, ref or in parameters needs. It never runs. Throws InvalidOperationException when a delegate made from it outside a selection is invoked.
TResult Ignored<TResult>()Names an event whose delegate returns a value and takes no parameters: () => bank.Asked += Arg.Ignored<bool>. C# infers type arguments from a delegate's parameters only, so the return type is written out. Throws InvalidOperationException when a delegate made from it outside a selection is invoked.
TResult Ignored<T1, TResult>(T1 a)Names an event whose delegate returns a value, with every type written out: Arg.Ignored<int, float>. Plain Arg.Ignored fits such an event; this form is for a second event in the assembly whose delegate has the same parameters and another return type. Overloads take up to 16 parameters. Throws InvalidOperationException when a delegate made from it outside a selection is invoked.

Leak detection

NonDeterministicAttribute

attr

Declares a member non-deterministic: its result differs between runs, machines or frames, so leak detection warns when a test reaches it for real. Every overload of the name is covered, and the declaration applies to the whole project, from any assembly that references Understudy: [assembly: NonDeterministic(typeof(ServerClock), nameof(ServerClock.Now))].
