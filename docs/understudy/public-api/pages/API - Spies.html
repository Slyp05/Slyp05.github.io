Public API Spies

What Spy entry points return: the real member runs, and the spy records what the code under test does with it. Explained in Check what the code under test did and Spy on caught exceptions. Every list a spy returns is live: it follows what the code under test does as it runs.

Methods

SpiedMethod

sealed

A spy on a void method: the real member runs, and each call the code under test makes that the selection matches is recorded. When it comes from a table, it covers its own instance only.

Every member throws InvalidOperationException once the test or fixture this spy belongs to has finished.

Members
CallList Calls { get; }The calls recorded, in the order the code under test made them.

sealed

A spy on a field: the real member is read and written, and each read and write the code under test makes that the selection matches is recorded. A selection through a chain follows the instance the chain reaches at each access; when it comes from a table, it covers its own instance only.

Events

SpiedEvent

sealed

A spy on an event: the real event keeps its handlers, and the spy records the handlers the code under test subscribes and the raises it makes. Handlers are kept per instance: a selection through a chain follows the instance the chain reaches at each access; when it comes from a table, it covers its own instance only.

Every member throws InvalidOperationException once the test or fixture this spy belongs to has finished.

Members
IReadOnlyList<RecordedHandler> Handlers { get; }The handlers the code under test subscribed while this spy exists and has not unsubscribed, in subscription order.
IReadOnlyList<RecordedInvocation> Invocations { get; }The raises the code under test made, in order.

Catch blocks

SpiedCatch<TException>

sealed

A spy on catch blocks: it records every catch block the code under test enters with an exception of its type, subtypes included, while it exists. TException derives from Exception.

Every member throws InvalidOperationException once the test or fixture this spy belongs to has finished.

Members
IReadOnlyList<RecordedCatch> Catches { get; }The catch blocks entered, in order.
