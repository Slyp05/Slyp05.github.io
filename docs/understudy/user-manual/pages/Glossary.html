Glossary

The terms the documentation uses.

Terms

TermDefinition
AccessA call, read or write the code under test makes to a member. A double records calls in Calls, and reads and writes in Reads and Writes.
AnswerWhat a stub does when it matches, set with Returns or Do, or EachReturns and EachDo on a table.
Assembly definition, test assemblyA file that compiles the scripts in its folder into an assembly of their own. A test assembly is one that references the Test Framework.
Catch spyA spy on the catch blocks the code under test enters with an exception type. Created with Spy.Catch<TException>().
Compilation stepThe part of Understudy that weaves your assemblies and reads the selections of test assemblies when Unity compiles scripts.
ContentThe value one recorded read or write carried.
DeclarationA spy, stub, fake or Real a test creates. When several match an access, the last one declared decides.
DoubleA spy, stub or fake, when the role doesn't matter.
Edit mode test, Play mode testA test that runs in the Editor without entering Play mode, or one that runs in Play mode, where Unity runs frames.
ElementAn item written with []: an array element or an indexer's value.
Entry pointThe method of Spy, Stub, Fake or Real that names a kind of member: Method, Constructor, Field, Property, Indexer or Event.
FakeA test double that replaces a member with a working in-memory stand-in: a stored value for a field or property, stored handlers for an event. Created with Fake.
Initial valueWhat a fake's stored value starts at in every test: its initial argument, a value or a factory.
InstanceThe object a member is reached through.
InvocationA raise of an event by the code under test, recorded in Invocations.
LeakAn access that ties a test to something outside it: a non-deterministic member or a global write the test didn't declare, or a real call to an overload of a member the test replaces.
Leak detectionThe warnings about leaks.
MatcherAn argument or index that matches by rule: Arg.Any, Arg.That.
MemberA method, constructor, field, property, indexer, event or user-defined operator of a type.
MockNo separate kind in Understudy: a stub replaces a member, and the test verifies calls through the Calls, Reads and Writes any double records.
Narrow, broadA selection that covers fewer accesses than another on the same member is narrower; one that covers more is broader.
Non-deterministic memberA member whose result differs between runs, machines or frames, declared with [NonDeterministic].
OrderThe sequence number of a recorded call, access, raise or catch, counted across every double in a test.
RealA declaration that a member runs for real on purpose. It overrides the stubs and fakes declared before it, and leak detection doesn't warn about the accesses it covers.
RoleWhat a declaration does with a member: Spy, Stub, Fake or Real.
SelectionThe lambda that names what a double or Real covers.
SpyA test double that runs the real member and records what the code under test does with it. Created with Spy.
Stored valueWhat a field or property fake holds, read and written through Value.
StubA test double that replaces a member with answers your test sets, through Returns and Do. Created with Stub.
TableThe doubles of one member on every instance, one per instance, reached with the instance as its index. A selection whose lambda takes the instance as its parameter returns one.
Test doubleAnything that stands in for a member during a test.
Test fixtureA class that holds tests. [SetUp] runs before each of its tests, [OneTimeSetUp] once before all of them.
WovenCode that Understudy rewrote so that tests can spy on, stub and fake its accesses.
