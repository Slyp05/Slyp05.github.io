Base values

Understand how plain writes work with modifiers, and read a value without them.

A member's base value is its value without modifiers. Concordance applies the active modifiers on top of it.

Plain writes

A plain write, an assignment without (Modifier), sets the base value:

AudioListener.volume = (Modifier)0f;   // a mute, from a cutscene
AudioListener.volume = 0.8f;           // from the options menu: the base value is 0.8, the value stays 0

A script that doesn't use Concordance therefore keeps working alongside the ones that do. An edit in the Inspector window in Play mode, animation, and reflection or JsonUtility.FromJsonOverwrite called from your scripts set the base value too.

Read the base value

Reading a member gives its value with the modifiers. GetUnmodified() gives the base value. Use it to change a member from its own value, and to save a member:

rb.gravityScale = rb.gravityScale.GetUnmodified() * 2f;   // doubles the base value
data.volume = AudioListener.volume.GetUnmodified();      // saves the volume, not a cutscene's mute

Without it, a write such as rb.gravityScale *= 2f reads the value with its modifiers, so they end up in the base value and apply twice, and a save stores the modifiers along with the value.
