Glossary

The terms the Selvage documentation uses.

Terms

TermDefinition
CandidateAn object that could be injected into a member. For more information, refer to Choose between several candidates.
Change, revokeWhat a provider announces about a dependency it gave: a change when a newer one exists and the old one is still usable, a revoke when it must not be used any more. For more information, refer to Reactive.
ChannelA value on a member, set with [Channel], that picks the candidate whose preference has the same value.
ContextAn object whose members Selvage injects: a MonoBehaviour, a ScriptableObject, an instance of a plain C# class, or a class, for its static members.
DefaultWhat a member holds when nothing is injected: its initializer, or null.
DependencyThe object a member holds.
FailWhat a required member does when its dependency is missing: it keeps its default, and the Console window displays an error.
Inject by DefaultThe setting that injects every class of the project. For more information, refer to Inject every class of the project.
Inject, reinject, releaseGive a member its dependency, give it a new one, and take it back.
LifetimeWhether members share one provided object (Shared), each receive their own (Separate), or borrow one from a pool (Pooled). For more information, refer to Lifetimes.
Local blockA using (Injector.Local(...)) block that gives objects to what you create inside it.
MemberA field or property marked [Inject], or covered by a scope.
MissingNo provider had a dependency for the member.
OptionA property of [Inject] that changes how a member is injected, such as Optional. For more information, refer to Options.
PreferenceSettings on a candidate that say which members it's for.
Provide DefinitionAn asset that makes Selvage provide the assets of its folder, or a list of assets.
Provide TuningA component that changes how the Scene Provider provides the GameObject it's on.
ProviderA class that gives dependencies from one source, such as the Scene Provider, which gives components from the loaded scenes.
Provider listThe ordered providers on the Selvage page of the Project Settings window. Selvage tries them from top to bottom.
ReadyA context is ready once all its members are injected, including its Async members.
RegistryA provider that gives the objects your code adds to it.
ScopeA class, an assembly or the project in which Selvage injects every field and property that can hold a dependency, without [Inject] on each.
SetupEverything on the Selvage page of the Project Settings window, saved to reuse in other projects.
Shipped providerA provider that ships with Selvage: the Registry Provider, the Scene Provider, the Attribute Provider and the Asset Provider.
WatchedA scene object whose Provide Tuning component announces when it appears and when it leaves, so members follow it. For more information, refer to Follow a scene object.
