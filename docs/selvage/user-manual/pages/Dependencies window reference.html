Dependencies window reference

The tabs, toolbar and results of the Dependencies window.

To open the Dependencies window, go to Tools > Selvage > Dependencies. Both tabs work in Edit mode and in Play mode.

Toolbar

ControlDescription
StateLists only the members in the checked states. With nothing checked, every state is listed. Outside Play mode, the states are the Validation results, and Failed lists the required members that are Missing. In Play mode, they're the Live states.
OptionsLists only the members with a checked option, or the members that only the Inject by Default setting injects. With nothing checked, every member is listed.
AssemblyLists only the members of contexts in one assembly.
StrictValidation tab only. Displays a required member that isn't Guaranteed as Missing.
AutoLive tab only. Reads the contexts again about every second, less often in a large scene. Enabled by default.
RefreshReads everything again: the results, and on the Live tab, the contexts and what each member holds.
ProvidersOpens the provider list.
Help (?)Opens the User Manual.

Above the members, a summary counts the members in each state. To list only the members in one state, select its count. Select several counts to combine them.

Validation tab

The Validation tab displays what each member will receive, read from your code and the provider list. What it lists depends on the selection:

SelectionLists
A script, or a GameObjectThe members of that script, or of each script on the GameObject.
A folderThe classes declared in the scripts of that folder.
Nothing, or Whole ProjectEvery class of the project that has injected members, with the classes that have a Missing member first.

Each member has one of the following results:

ResultDescription
GuaranteedA provider always gives the member a dependency.
May Be SuppliedA provider can give one, but whether it does is only known when the member is injected.
MissingNo provider gives the member a dependency. A required member fails.

The whole-project list has a search field, which matches class, namespace and member names, Expand Missing, which opens every class with a Missing member, and Collapse All. Each closed class displays its number of members, and how many are May Be Supplied and Missing. To move through the list with the keyboard, use the arrow keys: Right or Enter opens a class or a member's explanation, and Left closes it.

In Play mode, a banner offers Show Live, which opens the Live tab.

Live tab

The Live tab displays what each injected member holds. The Live Contexts list holds the contexts with injected members, under the following headings: each loaded scene, Kept Across Scene Loads, Assets, Plain Objects and Static (each class with injected static members). Outside Play mode, it holds only the contexts with EditMode members. Selecting an object in the Hierarchy or the Project window displays its contexts, with the static members of their classes; when it has none, the tab says whether the object has no injected members or isn't injected yet.

A static member reads static before its name: it holds one dependency for its class, shared by every object of it.

Each member of the selected context has one of the following states:

StateDescription
InjectedThe member holds its dependency.
WaitingThe member waits for an Async dependency. For more information, refer to Find out what a member waits for.
MissingThe member is Optional, and no provider gave it a dependency.
FailedThe member is required, and no provider gave it a dependency.

Each context in the list displays a dot for its worst member: red for Failed, amber for Missing, blue for Waiting, and green when every member is Injected. Its tooltip gives the counts. When you select several contexts, with Ctrl or Shift, each displays these counts, which you can select to list only that state.

Explain

Explain, on a member's row, lists every provider in the order Selvage tries them, and highlights the one that gives the member its dependency: on the Live tab, the provider that gave it, and on the Validation tab, the first provider that always gives it. The providers below it are dimmed, because Selvage doesn't ask them. Explain creates no object.
