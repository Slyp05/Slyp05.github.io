Project Settings reference

The providers, Inject by Default and validation settings on the Selvage page of the Project Settings window.

To open the Selvage page, go to Edit > Project Settings > Selvage, or to Tools > Selvage > Settings. Selvage saves the page in ProjectSettings/SelvageSettings.asset. Commit that file so your team and your build machines use the same settings. To find the file, select Show in Explorer (Reveal in Finder on macOS) at the bottom of the page.

Providers

The Providers section holds the provider list. Selvage tries the providers from top to bottom.

ControlDescription
+Adds a provider. The menu lists the providers that ship with Selvage, then the provider classes of your project.
-Removes the selected provider.
A provider's foldoutShows the provider's settings, and what it gives. A collapsed provider summarizes its settings at the end of its row.

A provider that code turned off with Enabled has a dimmed title, and its summary reads Off. A provider whose class isn't in the project, such as after a rename or from a setup of another project, is an error row that keeps its place and settings until the class is back.

Providers that code adds with Injector.AddFirst and Injector.AddLast appear above and below the list, read-only, each with a link to the line of code that added it. For more information, refer to Manage the provider list.

Scene Provider

The Scene Provider's settings apply to every member it serves. The list can hold several Scene Providers, each with its own settings.

PropertyDescription
ReachHow far from the member's GameObject the provider looks. Each value includes the ones before it. Among the components that preferences leave tied, the closest one wins.
  • Self: the member's own GameObject.
  • Hierarchy: also its parents and children.
  • Scene: also the rest of its scene.
  • All Scenes: also the other loaded scenes. This is the default.
Parents FirstLook at the parents before the children, when Reach includes the hierarchy. Enabled by default.
Include InactiveAlso give components on inactive GameObjects. Disabled by default.

Inject by Default

The Inject by Default section injects every class of every assembly that references Selvage, as if each assembly had [assembly: Inject]. For more information, refer to Inject every class of the project.

PropertyDescription
EnabledInjects every class of the project. To leave out an assembly, a class or a member, add [DontInject] to it.
Option togglesThe options every member receives, unless its own [Inject], its class or its assembly sets them. Optional is enabled by default.
Apply and RecompileSaves the changes and recompiles your scripts. Appears while a change is pending, and is unavailable in Play mode.
RevertDiscards the pending changes.

Validation

The Validation section runs the check of the Validation tab of the Dependencies window when you build and when you enter Play mode. For more information, refer to Validate when you build or enter Play mode.

PropertyDescription
Strict ValidationTreats a required member that no provider is guaranteed to give as Missing, so that every required dependency is proven in the Editor. Disabled by default.
Build ValidationWhat a build does when a member is Missing: Off, Warn, or Block. The default is Block.
Play ValidationWhat entering Play mode does when a member is Missing: Off, Warn, or Block. The default is Off. The check reads every type in the project, which slows the first entry into Play mode after each script change.

Setups menu

A setup is everything on the Selvage page. The More (⋮) menu at the top right of the page contains the following items:

ItemDescription
Default, and your setupsReplaces the page with that setup. Default is the setup that ships with Selvage.
Save Setup...Saves the page under a name, for every project on this computer.
Delete SetupDeletes one of your setups.
Save Setup to File..., Load Setup from File...Saves or loads a setup as a .json file, to share it with another computer or person.

The help button beside the menu opens the User Manual.
