Value type

InfVal

struct

Infinite-precision value type. Represents digits × 10exponent. Immutable on the public side. Implements IComparable, IComparable<InfVal>, IEquatable<InfVal>, IConvertible.

Formatting

IInfValFormatter

interface

Implement this interface to define how an InfVal is formatted to and parsed from a string. Mark the implementing class [Serializable] so it can be used inside a FormatterAsset.

Methods
string Format(in InfVal value) Convert an InfVal to its string representation.
void Format(in InfVal value, List<string> parts, int partCount = 0) Fill parts with the pieces of the formatted value: the number first, then a unit, or an exponent marker and its digits. Concatenating them gives what Format returns, except that a part merged from several never starts with a separator between the number and its unit, which is left out instead. partCount of 0 or less asks for the natural split, a positive value for exactly that many pieces, up to InfValFormatHelper.maxPartCount (16). Has a default implementation putting the whole output in a single part, so implementing it is optional. Throws ArgumentNullException if parts is null, or ArgumentOutOfRangeException if partCount is above 16.
bool TryParse(string text, out InfVal result) Try to convert a string to an InfVal. Return false (and set result to default) if the string is not a valid complete number.
bool IsValidPartialInput(string text) Return true if the text is either fully valid or a valid partial input that could still become valid (e.g. "-", "1.", "1e+"). Used by InfValInputField in DisallowInvalid mode.

ConwayGuyFormatter

class

IInfValFormatter that names each power of a thousand with the Conway-Guy system: 1.5 Thousand, 2.34 Quinquadecillion, 1 Millinillion for 103003, 150 Millionths for 1.5e-4. Names are generated for any magnitude, on the short or the long scale, and values that fit in maxDisplayedDigits are written in full. In Format into parts, the space before a name is a part of its own, left out when 2 parts are asked for: ["1.5", " ", "Million"], or ["1.5", "Million"]. Parsing ignores case and whitespace.

Public Fields
bool longScaleUse the long scale, where each -illion is a million times the previous one and the powers between them are -illiard (109 Milliard, 1012 Billion, 1015 Billiard), instead of the short scale (109 Billion, 1012 Trillion). Default: false.
bool capitalizeNamesWrite the first letter of each name in upper case. Default: true.
int maxDisplayedDigitsDefault: 4.
