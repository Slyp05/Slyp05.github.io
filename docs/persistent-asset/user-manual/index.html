Quick Usage Guide

Installation

Import Persistent Asset, run the demo, and find the settings and tools the package adds to your project.

Ways to save

Data class

Write a class of your own whose serialized fields are what the package saves and loads.

Prefs

Save a single value from anywhere in your code, with one line and nothing to set up.

No-Code

Persist values and build a save menu from the Inspector window, without writing a script.

Scene Objects

Save what your scene holds: the state of an object, whether it still exists, and references to it.

What can be saved

Choose the serializer that decides which of your fields end up in the save.

Saving and loading

How saving works

Learn what a persistent asset is, when it loads and saves, and when its data is safe to read.

Save and load

Control when a load or a save runs, react to it from your own code, and hook into the operations around it.

Slots and save menus

Give a player several saves at once: slots, a quick save ring, New Game and Continue.

Update a shipped save

Change the shape of a save that already shipped, and erase a player's data on request.

Where it is stored

Save on the device

Store a save on the player's own machine with one of the built-in local managers.

Save per platform

Route one persistent asset to a different storage on each platform you ship to.

Cloud & remote

Store a save off the device: on your own server, on Unity Cloud Save, or on Steam.

Connect to a backend service

Fill in the Server (HTTP) manager for PlayFab, Firestore, Supabase and other backend services.

Secure saves

Compress, encrypt and lock a save, on a file and on a server.
